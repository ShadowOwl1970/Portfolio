# Samantha Altamirano Portfolio

Starter build for a custom GitHub Pages portfolio.

## Included
- Responsive navigation
- Hero using the SA logo and owl mascot
- Brand palette from the existing style guide
- Selected work section
- Featured Hearth placeholder
- Project cards
- About preview
- Contact/footer
- Mobile menu
- Reduced-motion accessibility support
