Alter Character Manager.

Alter is a character management and roleplay tool built for Root communities, designed to help users create characters, manage identities, and roleplay through proxy-style messaging.

Overview

Roleplay identities, without the clutter.

Alter was created to make character-based roleplay easier to manage inside Root communities.

The app allows users to create and organize multiple characters, assign names, aliases, prefixes, and avatars, and use those characters in conversation without manually changing identity every time they speak.

Unlike a static design concept, Alter became a fully developed and released product with both bot commands and a companion management interface.

The challenge

Multiple characters, one account.

Roleplayers often need to switch between multiple fictional identities while still using the same Root account.

Without a dedicated system, users would have to manually identify the character speaking, manage names and avatars separately, or rely on inconsistent formatting.

Alter needed to make character switching fast and intuitive while staying within Root's app, bot, storage, and permission constraints.

Constraints

Designing inside the platform.

Alter was designed around the technical limitations and permission model of the Root platform.

Character avatars could not be uploaded directly through Alter, so the system uses image URLs instead.

The app also needed to work with Root's bot and app SDK, channel permissions, account linking, app packaging, and deployment workflow.

These constraints shaped both the user interface and the development approach from the beginning.

Branding

A flexible identity for many identities.

Alter's brand needed to feel distinct without competing with the characters users create inside the product.

The visual identity centers on a simplified profile silhouette, reinforcing the concept of identity, switching, and character representation.

The brand uses flat color and gradients rather than hyperrealistic imagery, keeping the interface modern, approachable, and adaptable across app icons, banners, gallery images, and promotional assets.

Character management

Everything in one place.

The companion interface gives users a visual way to manage characters outside of command-only interactions.

Users can create, edit, delete, and view characters from the manager interface while maintaining important information such as name, prefix, alias, and avatar URL.

Account-linking functionality connects the management experience to the user's Root identity, helping the interface feel like part of the larger platform rather than a disconnected tool.

Bot experience

Characters that speak for themselves.

Alter combines character management with proxy-style roleplay messaging.

Users can create characters through commands, review character information, update avatar URLs, manage aliases, and remove characters when they are no longer needed.

Prefix proxying lets users deliberately choose which character is speaking, while auto proxy provides a faster option for continuous roleplay.

Once a message is successfully proxied, the original message can be removed so the resulting conversation stays immersive.

Development

Designing it was only half the work.

Alter became an opportunity to move beyond interface design and work directly with product development.

The project uses Node.js and TypeScript alongside Root's server bot and server app SDKs.

The companion interface was built with React and Vite, while bot commands and messaging behavior were developed around the platform's server-side systems.

Development required troubleshooting issues involving message permissions, channel visibility, account linking, timeouts, ID mismatches, avatar handling, and deployment.

Iteration

Release, test, improve.

Alter has continued to evolve after its initial release.

Early development focused on getting the complete proxy workflow functioning reliably, including character commands, account linking, message handling, and deletion behavior.

Later versions introduced planning around optimization, refresh behavior, additional character functionality, and a cleaner path for future updates.

Maintaining version backups also became part of the workflow, helping protect stable releases while new features were tested.

Final result

A working product, not just a prototype.

Alter brings character creation, management, and proxy messaging together inside the Root ecosystem.

The project demonstrates how branding, interface design, user experience, technical constraints, and development can work together as one product process.

It also provides a foundation for future character-focused features as the product and Root platform continue to evolve.

Reflection

Learning by building.

Alter pushed me to think about product design from both the user's perspective and the implementation side.

Designing within a real platform meant that every interface decision had to account for permissions, available APIs, technical limitations, and actual user behavior.

The project strengthened my experience with front-end development, troubleshooting, iterative releases, and designing systems that need to remain maintainable after launch.
